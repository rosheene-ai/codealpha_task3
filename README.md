# task-3: Basic Chatbot

CodeAlpha Python Programming Internship - Basic Chatbot task.

A simple rule-based chatbot.

## Features
- Replies to "hello", "how are you", "bye"
- Extra commands: name, time, help
- Runs in a loop until the user says bye

## Run
```
python chatbot.py
```
Requires Python 3.8+ (no external libraries).

## Concepts Used
if-elif, functions, loops, input/output
